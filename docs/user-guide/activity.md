# Activity

The **Activity** page provides an overview of wildlife activity recorded by
WAMF during the current day.

It summarises detection numbers, hourly activity and the species that have
been most active.

## Observatory Activity

The **Observatory Activity** section provides three headline statistics for
the current day:

- **Total Detections** — total number of wildlife detections recorded today.
- **Species Seen** — number of different species detected today.
- **Busiest Hour** — the hour containing the most detections.

When no detections have been recorded during the current day, the detection
and species counts are shown as zero and no busiest hour is displayed.

## Activity by Hour

The **Activity by Hour** section shows how detections have been distributed
throughout the current day.

This provides a quick view of periods with higher or lower wildlife activity.

## Top Active Species

The **Top Active Species** section shows which species have generated the
most detections during the current day.

## Species Peak Activity

The **Species Peak Activity** section provides information about when
individual species have been most active during the current day.

## Viewing Previous Days

The Activity page covers the **current day**.

To review activity from a previous date, use the calendar picker on the
Overview page. Selecting a date opens the [Daily Summary](daily-summary.md),
which provides species and hourly activity for that day.

For detailed information and detection history for an individual species,
see [Species](species.md).
